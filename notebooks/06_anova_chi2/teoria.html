12  ANOVA, Chi-cuadrado y Pruebas No Paramétricas

12.1 6.1 Introducción

En el Módulo 4 aprendimos a comparar dos grupos (un test t o z), y en el Módulo 5 a estudiar la relación entre dos variables numéricas. Pero en la práctica surgen preguntas que esas herramientas no cubren:

  • ¿Y si quiero comparar tres o más grupos a la vez (tres tratamientos, cuatro campañas, cinco segmentos)?
  • ¿Y si mis variables no son numéricas, sino categóricas (sexo, segmento de cliente, tipo de producto)?
  • ¿Y si mis datos claramente no siguen una distribución Normal y no puedo asumir las condiciones de un t-test?

Este módulo cierra esos tres huecos, y de paso conecta con el mundo del machine learning: comparar grupos, tablas de contingencia y pruebas robustas frente a la normalidad son herramientas que reaparecen constantemente en la validación de modelos y en la selección de variables.

12.2 6.2 ANOVA de un Factor

12.2.1 El problema de comparar 3+ grupos con t-tests repetidos

Si quisiéramos comparar tres tratamientos médicos, una tentación es hacer tres t-tests por pares (A vs B, A vs C, B vs C). El problema es que cada test individual tiene un 5% de probabilidad de un falso positivo (error Tipo I), y al repetir tests esa probabilidad se acumula: con tres comparaciones, la probabilidad de al menos un falso positivo sube por encima del 5% nominal. El ANOVA (Análisis de la Varianza) resuelve esto con un único test que compara los tres grupos a la vez.

12.2.2 Hipótesis e idea central

\[ H_0: \mu_1 = \mu_2 = \dots = \mu_k \qquad H_1: \text{al menos una media es distinta} \]

La idea, pese al nombre “análisis de la varianza”, es comparar medias: descompone la variabilidad total de los datos en dos partes:

  • Varianza entre grupos: cuánto difieren las medias de cada grupo respecto a la media global.
  • Varianza dentro de grupos: cuánto varían los datos dentro de cada grupo (el “ruido” natural).

Si la variabilidad entre grupos es mucho mayor que la variabilidad dentro de los grupos, es señal de que las diferencias observadas no se deben solo al azar:

\[ F = \frac{MS_{\text{entre}}}{MS_{\text{dentro}}} = \frac{SS_{\text{entre}} / (k-1)}{SS_{\text{dentro}} / (n-k)} \]

donde \(k\) es el número de grupos y \(n\) el número total de observaciones. Bajo \(H_0\), este estadístico sigue una distribución F con \((k-1, n-k)\) grados de libertad.

Código 
from stats_toolkit import group_comparisons as gc

# Días de recuperación de pacientes bajo 3 tratamientos distintos
tratamiento_a = [5, 6, 7, 5, 6, 8, 6]
tratamiento_b = [8, 9, 7, 10, 8, 9, 9]
tratamiento_c = [4, 5, 4, 6, 5, 5, 4]

f_stat, p_value = gc.anova_one_way(tratamiento_a, tratamiento_b, tratamiento_c)
print(f"F = {f_stat:.3f}, p-valor = {p_value:.6f}")
F = 29.946, p-valor = 0.000002

Un p-valor por debajo de 0.05 indica que al menos un tratamiento difiere significativamente de los demás en tiempo de recuperación — aunque el ANOVA por sí solo no dice cuál; para eso harían falta comparaciones post-hoc (fuera del alcance de este módulo introductorio).

12.3 6.3 Test Chi-cuadrado de Independencia

Cuando ambas variables son categóricas (por ejemplo, segmento de cliente y producto preferido), no tiene sentido hablar de medias. En su lugar, organizamos los datos en una tabla de contingencia (frecuencias observadas cruzando ambas variables) y contrastamos si existe asociación entre ellas.

\[ H_0: \text{las dos variables son independientes} \qquad H_1: \text{existe asociación entre ellas} \]

El estadístico compara las frecuencias observadas con las que esperaríamos si las variables fueran realmente independientes:

\[ \chi^2 = \sum_{i,j} \frac{(O_{ij} - E_{ij})^2}{E_{ij}} \]

donde \(E_{ij}\) es la frecuencia esperada bajo independencia, calculada a partir de los totales de fila y columna. Sigue una distribución Chi-cuadrado con \((filas-1)(columnas-1)\) grados de libertad.

Código 
import pandas as pd

# Segmento de cliente vs. producto preferido
segmento = ["Joven"]*40 + ["Joven"]*10 + ["Adulto"]*20 + ["Adulto"]*30 + ["Senior"]*15 + ["Senior"]*35
producto = ["Digital"]*40 + ["Físico"]*10 + ["Digital"]*20 + ["Físico"]*30 + ["Digital"]*15 + ["Físico"]*35

tabla = gc.build_contingency_table(segmento, producto)
print(tabla)
Y       Digital  Físico
X                      
Adulto       20      30
Joven        40      10
Senior       15      35
Código 
chi2_stat, p_value, dof, esperadas = gc.chi2_test_independence(tabla)
print(f"\nChi² = {chi2_stat:.3f}, p-valor = {p_value:.6f}, g.l. = {dof}")

if p_value < 0.05:
    print("Hay evidencia de asociación entre segmento de cliente y producto preferido")
else:
    print("No hay evidencia suficiente de asociación entre ambas variables")

Chi² = 28.000, p-valor = 0.000001, g.l. = 2
Hay evidencia de asociación entre segmento de cliente y producto preferido

12.4 6.4 Pruebas No Paramétricas: Mann-Whitney U

Tanto el t-test como el ANOVA asumen que los datos siguen (aproximadamente) una distribución Normal dentro de cada grupo. Cuando esa suposición no se sostiene — muestras muy pequeñas, datos claramente asimétricos, escalas ordinales (por ejemplo, valoraciones de 1 a 5) — recurrimos a pruebas no paramétricas, que no hacen ninguna suposición sobre la forma de la distribución.

El test de Mann-Whitney U es la alternativa no paramétrica al t-test de dos muestras independientes. En vez de comparar medias, compara si los valores de un grupo tienden a ser sistemáticamente mayores (o menores) que los del otro, trabajando con los rangos de los datos combinados en vez de con sus valores originales.

\[ H_0: \text{ambas distribuciones son iguales} \qquad H_1: \text{una tiende a tomar valores mayores que la otra} \]

Código 
# Valoraciones de satisfacción (escala 1-10) de dos versiones de una app,
# claramente no normales (concentradas en los extremos)
valoraciones_v1 = [2, 3, 2, 9, 3, 2, 8, 3, 2, 9]
valoraciones_v2 = [5, 6, 7, 6, 5, 7, 6, 5, 6, 7]

u_stat, p_value = gc.mann_whitney_u(valoraciones_v1, valoraciones_v2)
print(f"U = {u_stat:.3f}, p-valor = {p_value:.6f}")

if p_value < 0.05:
    print("Hay diferencia significativa entre las distribuciones de valoraciones de ambas versiones")
else:
    print("No hay evidencia suficiente de diferencia entre versiones")
U = 30.000, p-valor = 0.135517
No hay evidencia suficiente de diferencia entre versiones

Este tipo de pruebas basadas en rangos, robustas frente a la forma de la distribución, son la razón por la que muchos algoritmos de machine learning (árboles de decisión, bosques aleatorios, tests de importancia de variables) prefieren criterios no paramétricos: no dependen de que los datos reales del mundo se comporten como una Normal perfecta.

12.5 6.5 Cierre

Este módulo amplía el curso más allá de los cinco módulos iniciales, cubriendo tres herramientas que aparecen constantemente en análisis con más de dos grupos o con variables categóricas: el ANOVA para comparar varias medias a la vez, el test Chi-cuadrado para relaciones entre variables categóricas, y el Mann-Whitney U como alternativa robusta cuando no se cumplen los supuestos de normalidad. Con esto, el conjunto de pruebas de hipótesis del curso queda prácticamente completo para cualquier análisis exploratorio o experimento aplicado — y sienta las bases para dar el salto hacia modelos predictivos más flexibles (regresión múltiple, clasificación) si decides continuar el curso en esa dirección.
