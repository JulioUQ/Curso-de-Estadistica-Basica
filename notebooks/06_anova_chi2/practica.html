14  Práctica: ANOVA, Chi-cuadrado y Pruebas No Paramétricas

En este cuaderno comparamos tres tratamientos médicos con ANOVA, estudiamos la asociación entre dos variables categóricas con un test Chi-cuadrado sobre una tabla de contingencia, y aplicamos Mann-Whitney U cuando los datos no siguen una distribución Normal.

14.1 ANOVA: efectividad de 3 tratamientos médicos

Comparamos el tiempo de recuperación (en días) de pacientes bajo tres tratamientos distintos.

Código 
rng = np.random.default_rng(5)
tratamiento_a = rng.normal(6, 1.2, size=15)
tratamiento_b = rng.normal(8.5, 1.2, size=15)
tratamiento_c = rng.normal(5, 1.2, size=15)

plt.boxplot([tratamiento_a, tratamiento_b, tratamiento_c], tick_labels=["Tratamiento A", "Tratamiento B", "Tratamiento C"])
plt.xlabel("Tratamiento")
plt.ylabel("Días de recuperación")
plt.title("Tiempo de recuperación por tratamiento")
plt.show()
Código 
f_stat, p_value = gc.anova_one_way(tratamiento_a, tratamiento_b, tratamiento_c)
print(f"F = {f_stat:.3f}, p-valor = {p_value:.3g}")

if p_value < 0.05:
    print("Hay evidencia de que no todos los tratamientos tienen la misma media.")
else:
    print("No hay evidencia suficiente de diferencias entre tratamientos.")

14.2 Chi-cuadrado: segmento de cliente vs. producto preferido

Construimos una tabla de contingencia a partir de datos simulados de clientes y comprobamos si el segmento de edad está asociado con el producto que prefieren.

Código 
rng = np.random.default_rng(9)
n_clientes = 300

segmento = rng.choice(["Joven", "Adulto", "Senior"], size=n_clientes, p=[0.4, 0.35, 0.25])

# La preferencia depende del segmento (para que haya una asociación real que detectar)
prob_digital = {"Joven": 0.8, "Adulto": 0.5, "Senior": 0.2}
producto = [
    rng.choice(["Digital", "Físico"], p=[prob_digital[s], 1 - prob_digital[s]])
    for s in segmento
]

tabla = gc.build_contingency_table(segmento, producto)

chi2_stat, p_value, dof, esperadas = gc.chi2_test_independence(tabla)
print(f"Chi² = {chi2_stat:.3f}, p-valor = {p_value:.3g}, g.l. = {dof}")

print("\nFrecuencias esperadas bajo independencia:")
print(pd.DataFrame(esperadas, index=tabla.index, columns=tabla.columns).round(1))

14.3 Mann-Whitney U: valoraciones no normales de dos versiones de una app

Simulamos valoraciones (escala 1-10) claramente no normales: la versión 1 tiene valoraciones polarizadas (o encanta o decepciona), mientras que la versión 2 tiene valoraciones más consistentes.

Código 
rng = np.random.default_rng(11)

# Distribución bimodal: mezcla de valoraciones muy bajas y muy altas
valoraciones_v1 = np.concatenate([
    rng.integers(1, 4, size=15),
    rng.integers(8, 11, size=15),
])
valoraciones_v2 = rng.integers(5, 8, size=30)

fig, axes = plt.subplots(1, 2, figsize=(10, 4), sharey=True)
axes[0].hist(valoraciones_v1, bins=range(1, 12), edgecolor="black")
axes[0].set_title("Versión 1 (polarizada)")
axes[1].hist(valoraciones_v2, bins=range(1, 12), edgecolor="black")
axes[1].set_title("Versión 2 (consistente)")
for ax in axes:
    ax.set_xlabel("Valoración")
axes[0].set_ylabel("Frecuencia")
fig.suptitle("Distribución de las valoraciones por versión de la app")
plt.tight_layout()
plt.show()
Código 
u_stat, p_value = gc.mann_whitney_u(valoraciones_v1, valoraciones_v2)
print(f"U = {u_stat:.3f}, p-valor = {p_value:.3g}")
print(f"Media v1: {valoraciones_v1.mean():.2f} | Media v2: {valoraciones_v2.mean():.2f}")

if p_value < 0.05:
    print("\nHay diferencia significativa entre las distribuciones de ambas versiones.")
else:
    print("\nNo hay evidencia suficiente de diferencia entre versiones.")
U = 450.000, p-valor = 1
Media v1: 5.50 | Media v2: 6.30

No hay evidencia suficiente de diferencia entre versiones.

Fíjate en lo que ocurre: las dos versiones tienen distribuciones muy distintas (la v1 polarizada, la v2 concentrada en el centro) y medias parecidas, pero Mann-Whitney no encuentra evidencia de diferencia. No es un fallo de la prueba: como vimos en la teoría, Mann-Whitney detecta sobre todo si los valores de un grupo tienden a ser mayores que los del otro, y aquí ninguna versión tiende a recibir valoraciones más altas (la v1 tiene tantas valoraciones por encima como por debajo de las de la v2). Por eso un p-valor grande no demuestra que las distribuciones sean iguales: esta prueba apenas detecta diferencias de dispersión o de forma como esta.

14.4 Caso real: estrés según el tipo de trastorno del sueño

Con los datos de sueño preparados en el Módulo 1 (sintéticos), comparamos el nivel de estrés (Stress) entre los tres grupos de SD: sin trastorno, insomnio y apnea del sueño. Aplicamos el ANOVA con su tamaño del efecto y las comparaciones de Tukey, y Kruskal-Wallis como alternativa basada en rangos, porque Stress es una puntuación entera.

Código 
sueno = pd.read_csv("../01_estadistica_descriptiva/data/sleephealth_processed.csv",
                    keep_default_na=False, na_values=[""])
grupos_sd = ["None", "Insomnia", "Sleep Apnea"]
estres_por_sd = [sueno.loc[sueno["SD"] == g, "Stress"].to_numpy(float) for g in grupos_sd]

plt.boxplot(estres_por_sd, tick_labels=["Sin trastorno", "Insomnio", "Apnea"])
plt.ylabel("Nivel de estrés")
plt.title("Estrés según el trastorno del sueño")
plt.show()

f_s, p_s = gc.anova_one_way(*estres_por_sd)
print(f"ANOVA: F = {f_s:.3f}, p-valor = {p_s:.3g}, η² = {gc.eta_squared(*estres_por_sd):.3f}")
h_s, p_kw = gc.kruskal_wallis(*estres_por_sd)
print(f"Kruskal-Wallis: H = {h_s:.3f}, p-valor = {p_kw:.3g}")
gc.tukey_hsd(*estres_por_sd, labels=["Sin trastorno", "Insomnio", "Apnea"]).round(4)

Lee juntos los tres resultados: el p-valor del ANOVA indica si hay evidencia de que no todas las medias son iguales, \(\eta^2\) indica qué parte de la variabilidad del estrés se asocia al tipo de trastorno, y la tabla de Tukey muestra qué parejas difieren (las de p-valor ajustado menor que 0,05). Comprueba también si Kruskal-Wallis llega a la misma conclusión. Como en el Módulo 5, son datos observacionales con muchas filas repetidas, así que el supuesto de independencia es dudoso.

tabla_sd = gc.build_contingency_table(sueno["Gender"], sueno["SD"])

display(tabla_sd)
print(f"Chi² = {chi2_g:.3f}, g.l. = {dof_g}, p-valor = {p_g:.3g}")
print(f"V de Cramér = {gc.cramers_v(tabla_sd):.3f}")
print(f"Mínima frecuencia esperada = {esperadas_g.min():.1f}")

14.6 Soluciones

Intenta resolver los ejercicios antes de desplegar cada solución. Las soluciones se ejecutan con los mismos datos y semillas que el resto del cuaderno.

TipSolución del ejercicio 1

Generamos los tres grupos con la misma media (6 días) y la misma desviación típica.

Código 
rng_igual = np.random.default_rng(21)
grupos_iguales = [rng_igual.normal(6, 1.2, size=15) for _ in range(3)]
f_igual, p_igual = gc.anova_one_way(*grupos_iguales)
print(f"F = {f_igual:.3f}, p-valor = {p_igual:.3g}")
F = 1.260, p-valor = 0.294

Con medias poblacionales iguales lo esperable es un F cercano a 1 y un p-valor grande: no hay evidencia de diferencias. Aun así, por azar, alrededor de un 5 % de las simulaciones darían \(p < 0{,}05\): es la probabilidad de error de tipo I.

TipSolución del ejercicio 2

Simulamos de nuevo las preferencias con tres productos, con probabilidades que dependen del segmento.

Código 
rng_prod = np.random.default_rng(9)
segmento_3 = rng_prod.choice(["Joven", "Adulto", "Senior"], size=300, p=[0.4, 0.35, 0.25])
prob_producto = {
    "Joven": [0.6, 0.15, 0.25],
    "Adulto": [0.4, 0.4, 0.2],
    "Senior": [0.15, 0.7, 0.15],
}
producto_3 = [rng_prod.choice(["Digital", "Físico", "Suscripción"], p=prob_producto[s]) for s in segmento_3]

tabla_3 = gc.build_contingency_table(segmento_3, producto_3)
display(tabla_3)
chi2_3, p_3, dof_3, _ = gc.chi2_test_independence(tabla_3)
print(f"Chi² = {chi2_3:.3f}, p-valor = {p_3:.3g}, g.l. = {dof_3}")

Los grados de libertad pasan de \((3-1)(2-1) = 2\) a \((3-1)(3-1) = 4\): con más categorías, hay más celdas que pueden variar libremente una vez fijados los totales de filas y columnas.

TipSolución del ejercicio 3

Aplicamos las dos pruebas a los mismos datos polarizados.

Código 
from scipy import stats

t_res = stats.ttest_ind(valoraciones_v1, valoraciones_v2)
u_v, p_u = gc.mann_whitney_u(valoraciones_v1, valoraciones_v2)
print(f"t-test:       t = {t_res.statistic:.3f}, p-valor = {t_res.pvalue:.3g}")
print(f"Mann-Whitney: U = {u_v:.1f}, p-valor = {p_u:.3g}")
print(f"Desviaciones típicas: v1 = {valoraciones_v1.std(ddof=1):.2f}, v2 = {valoraciones_v2.std(ddof=1):.2f}")
t-test:       t = -1.136, p-valor = 0.261
Mann-Whitney: U = 450.0, p-valor = 1
Desviaciones típicas: v1 = 3.78, v2 = 0.79

Ninguna de las dos encuentra evidencia de diferencia, y es coherente: el t-test compara las medias, que aquí son parecidas, y Mann-Whitney busca que una versión tienda a recibir valoraciones más altas, cosa que tampoco ocurre. La diferencia real entre las versiones está en la dispersión (la v1 está polarizada), y ninguna de estas pruebas está diseñada para detectarla. La prueba adecuada depende de la pregunta: si interesa la satisfacción media, ambas responden algo parecido; si interesa la polarización, habría que comparar la dispersión, por ejemplo con la prueba de Levene (scipy.stats.levene).
